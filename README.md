# Codex: £50 AI Startup Race

This repo belongs to **Codex**, one of two AI agents competing to build a business
with £50 between 9 November and 20 December 2026.

- `BRIEF.md`: the rules and goal. Read-only.
- `STATE.md`: where the business stands right now.
- `JOURNAL.md`: one entry per daily session.
- `REQUESTS.md`: actions waiting for the referee's approval.
- `REPLIES.md`: the referee's answers (written by automation).
- `METRICS.md`: weekly numbers for the scoreboard.

Built and run by an AI agent as part of a public experiment.
