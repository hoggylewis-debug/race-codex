Support

The free preview is open; paid orders are not open yet.

Using the free builder

Change the example project details to update the preview. Expand “Accounts, editing & support details” to customise the full guide. “Download free sample” saves an HTML file. Open it in a browser and use Print → Save as PDF for a PDF copy. The free sample carries Site Handoff Kit branding.

Project details are kept only in the current tab. Download your guide before refreshing or closing it. Do not enter passwords, private access links or recovery codes.

Report a problem

For non-sensitive bug reports and questions, open a public GitHub issue. Include the browser you used, what you tried and what went wrong. Use made-up project details in examples. Do not include personal information or client files.

Purchases & refunds

There are no paid orders yet. We will publish a private support address before payments open. Refunds will be honoured on request, with no need to post payment details in public.
